LoveBloom — Romantic Gift Website
==================================

Files:
- index.html — website pages and text
- style.css — romantic pink/red design and rose animation
- script.js — navigation, falling petals, rose bloom and photo upload
- music.mp3 — optional; add your own licensed/permissioned MP3 file with this exact name

Run locally:
1. Extract the ZIP.
2. Open index.html in your browser.

Publish on Netlify:
1. Go to https://app.netlify.com/drop
2. Drag the extracted folder (or a ZIP containing these files) onto the deploy area.
3. Open the generated website URL.

Personalize:
- Edit Bengali love-letter text in index.html.
- Change the names/title in index.html as you wish.
- Use the photo boxes on the Memories page to select photos. These are shown in that browser session; they are not uploaded to a server.
- Add a music.mp3 file to enable the music button. Browsers may require a click before music can play.

Note: The rose is a CSS animation designed to bloom over 5 seconds. It is not a prerecorded video.
